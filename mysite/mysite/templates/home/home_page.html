j0e1.dev's Blogpost CMS

This is a custom Content Management System built with Wagtail and Django. I created this project to deepen my understanding of CMS architecture, content workflows, and how they differ from traditional Django applications.

Project Highlights

Built with Wagtail

A powerful, open-source CMS framework built on Django that makes content management intuitive and developer-friendly.

Custom Blog Engine

Fully-featured blog system with custom models, templates, and a clean interface for publishing and managing content.

Learning Project

A hands-on exploration of CMS concepts, page hierarchies, media management, and Wagtail's admin interface.

About This Project

This CMS demonstrates key Wagtail features including:

  • Page-based content hierarchy and inheritance
  • Custom page types (Blog Index and Blog Posts)
  • Media management with image optimization
  • SEO-friendly URL structures
